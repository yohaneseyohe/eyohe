Yohanes Mesfin — EYOHE

Two ways of looking at the same system: how it breaks, and how it should have been built.

I'm Yohanes Mesfin — building and researching under the name EYOHE. My work starts from an attacker's questions: where is trust assumed, what happens when input isn't what's expected, what's reachable that shouldn't be. Those questions shape how I build — authentication, authorization, data handling, and validation are design decisions made early, not patched in later.

On the development side, I build web applications, Android apps, and iOS apps end to end, treating user trust as something earned through engineering, not claimed in a footer badge.
